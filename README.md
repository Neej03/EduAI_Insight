## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Neej03/EduAI_Insight.git
```

Navigate to the project folder:

```bash
cd EduAI_Insight
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```
